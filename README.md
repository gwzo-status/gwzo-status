# GWZO IT-Statusseite

Quelle der Statusseite des GWZO für den IT-Notfall (IT-Notfallplan Kap. 5.2/5.3).

- **https://gwzo-status.github.io**: dieses Repo, ohne eigene Domain. Bleibt auch erreichbar, wenn das DNS von leibniz-gwzo.de manipuliert ist.
- **https://status.leibniz-gwzo.de**: automatischer Spiegel im Repo `Leibniz-GWZO/status` (Organisation Leibniz-GWZO, dort ist leibniz-gwzo.de verifiziert) (siehe `.github/workflows/spiegel.yml`). Das Repo `status` nie direkt bearbeiten.

**Bearbeiten:** nur `index.md`. Vorlagen stehen im Kommentarblock derselben Datei.
